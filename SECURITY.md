# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | ✅ Yes |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Email us directly: `security@synexian.dev`

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix if you have one

We will acknowledge receipt within 48 hours and aim to release a fix
within 14 days for critical vulnerabilities.

## Responsible Disclosure

We follow responsible disclosure. Please give us reasonable time to
fix the issue before public disclosure.

## Scope

In scope:
- Security vulnerabilities in Aegis itself
- Credential or secret exposure bugs
- Code injection via malformed input

Out of scope:
- Vulnerabilities in third-party tools (bandit, radon, flake8, etc.)
- Issues requiring physical access to the user's machine
